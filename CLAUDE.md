# Darsi (درسي) — notes for Claude Code

Darsi is a serious upskilling PWA for school and university teachers (and their students) in developing countries. It covers AI, IoT and cyber security, in English and Arabic (RTL and LTR). It runs on Firebase now, with Capacitor for Android/iOS later.

## Layout
- `packages/design-system`: @darsi/design-system (tsup; tokens.json → CSS/TS/Tailwind; 45 RTL-aware components). Build it first: `npm run build -w @darsi/design-system`.
- `apps/web`: Vite 8 + React 19 + TS 6, react-router 7, vite-plugin-pwa, Capacitor 8, firebase 12, exceljs, pptxgenjs.
- Docs: `README.md` covers the concept and the why (brand voice; logo from `packages/design-system/assets/logos`). `TECHNICAL.md` is the technical reference: architecture, data model, rules, functions, caching, sync, CSS, tests, budget. Keep it current when you change those.
- `functions/`: Cloud Functions v2 (Node 22, region europe-west1): org requests and approval, invite codes, bulk member creation with random passwords, role changes, password reset, the progress → summary trigger.
- `firebase/`: firestore.rules, storage.rules, firestore.indexes.json. `firebase.json` at the root holds hosting, emulators and headers.
- Content: the app ships no courses; every course comes from the course editor (published to Storage). The starting courses are sources in `content/units/*.json` (repo root) with kits in `content/kits/` (generated by `apps/web/scripts/build-kits.mjs`) and media in `content/media/` (gitignored; from `scripts/import-packs.mjs` for the three pack courses, `scripts/import-media.mjs` for the rest), published with `npm run seed` (`--emulator` for the emulators). 24 courses: per track, one per level for teachers and one for students (`docs/CURRICULUM.md`, per-track plans in `docs/curriculum/`). Retired courses are in `content/retired/` (`ai-1`, still the test course). `apps/web/public/content/placement.json` (the onboarding check) is the only content the app ships.

## Conventions
- Use npm 11 (`npx -y npm@11.13.0 install` if npm 10 crashes with "edgesOut").
- Pin dependency versions that are at least two weeks old.
- Arabic text: never use "·" as a separator (it reads as Arabic zero). Use "،" or the i18n key `common.sep`.
- Arabic words on a page in another language (a language's own name, the Arabic brand name) get `lang="ar"` and `className="dr-other-script"`, so they use the phone's font and English pages never download the Arabic web fonts. The e2e test "an English page never downloads the Arabic or extended-Latin fonts" guards this.
- The app is light theme only. Do not add dark mode.
- Custom claims {role, orgId} are set only by Cloud Functions. Roles: learner, student, teacher, orgAdmin, superadmin.
- Username logins map to `<username>@users.darsi.app` (in `auth/api.ts` and `functions/src/passwords.ts`; keep the two in sync).
- Commit to git only when the user asks.
